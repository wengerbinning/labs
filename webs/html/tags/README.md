* `<slot>`: this element—part of the Web Components technology suite—is a placeholder inside a web component that you can fill with your own markup, which lets you create separate DOM trees and present them together.
* `<small>`: this element represents side-comments and small print, like copyright and legal text, independent of its styled presentation.

#### T

* `<table>`: this element represents tabular data—that is, information presented in a two-dimensional table comprised of rows and columns of cells containing data.
* `<tbody>`: this element encapsulates a set of table rows (<tr> elements), indicating that they comprise the body of a table's (main) data.
* `<td>`: this element defines a cell of a table that contains data and may be used as a child of the <tr> element.
* `<template>`: this element serves as a mechanism for holding HTML fragments, which can either be used later via JavaScript or generated immediately into shadow DOM.
* `<textarea>`: element represents a multi-line plain-text editing control, useful when you want to allow users to enter a sizeable amount of free-form text, for example a comment on a review or feedback form.
* `<tfoot>`: this element encapsulates a set of table rows (<tr> elements), indicating that they comprise the foot of a table with information about the table's columns.
* `<th>`: this element defines a cell as the header of a group of table cells and may be used as a child of the <tr> element.
* `<thead>`: this element encapsulates a set of table rows (<tr> elements), indicating that they comprise the head of a table with information about the table's columns.
* `<time>`: this element represents a specific period in time.
* `<title>`: This element defines the document's title that is shown in a browser's title bar or a page's tab.
* `<tr>`: this element defines a row of cells in a table.
* `<track>`: this element is used as a child of the media elements, `<audio>` and `<video>`.
* ~~`<tt>`~~: this element creates inline text which is presented using the user agent's default monospace font face.

#### U

* `<u>`: this element represents a span of inline text which should be rendered in a way that indicates that it has a non-textual annotation.
* `<ul>`: this element represents an unordered list of items, typically rendered as a bulleted list.

#### V

* `<var>`: This element represents the name of a variable in a mathematical expression or a programming context.
* `<video>`: This element embeds a media player which supports video playback into the document.

#### W

* `<wbr>`: This element represents a word break opportunity—a position within text where the browser may optionally break a line, though its line-breaking rules would not otherwise create a break at that location.
