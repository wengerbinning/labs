Flexbox 弹性盒子布局

一维布局模型，用于在行或列中排列元素。特别适合处理未知或动态尺寸的元素。

主轴 (Main Axis)

由 flex-direction 定义方向

交叉轴 (Cross Axis)

与主轴垂直的方向

Flexbox核心思想

Flexbox的核心是容器和项目的关系。容器控制其内部项目的排列、对齐和分布。项目可以根据可用空间自动调整大小，也可以指定固定的尺寸。

容器属性 父元素设置

display: flex;
将一个元素定义为Flex容器，其直接子元素自动成为Flex项目。
flex inline-flex
flex-direction
定义主轴方向，决定项目的排列方向。
row row-reverse column column-reverse
justify-content
定义项目在主轴上的对齐方式。
flex-start flex-end center space-between space-around space-evenly
align-items
定义项目在交叉轴上的对齐方式。
stretch flex-start flex-end center baseline

项目属性 子元素设置

flex-grow
定义项目的放大比例，默认为0（不放大）。
0 1 2 n
flex-shrink
定义项目的缩小比例，默认为1（空间不足时缩小）。
0 1 2
flex-basis
定义项目在分配多余空间之前的主轴尺寸。
auto 0 100px 20%
align-self
允许单个项目有与其他项目不一样的对齐方式。
auto flex-start flex-end center stretch

CSS Grid 网格布局

二维布局系统，可以同时处理行和列。非常适合构建复杂的网页布局。

Grid核心思想

Grid布局将容器划分为"网格"，通过定义行和列来创建二维布局。你可以精确控制每个项目在网格中的位置和大小，甚至可以创建重叠的元素。

容器属性 父元素设置

display: grid;
将一个元素定义为Grid容器，其直接子元素自动成为Grid项目。
grid inline-grid
grid-template-columns
定义网格的列数和每列的宽度。
repeat(3, 1fr) 200px 1fr 300px minmax(100px, 1fr) auto
grid-template-rows
定义网格的行数和每行的高度。
100px 200px auto minmax(50px, auto) 1fr 2fr
grid-template-areas
通过命名网格区域来定义布局模板。
"header header" "sidebar main" "footer footer"

项目属性 子元素设置

grid-column
定义项目在列上的起始和结束位置。
1 / 3 span 2 2 / span 2
grid-row
定义项目在行上的起始和结束位置。
2 / 4 span 3 1 / span 2
grid-area
为项目指定名称，或指定在grid-template-areas中的位置。
header sidebar 1 / 1 / 3 / 3
justify-self
定义单个项目在水平方向上的对齐方式。
stretch start end center

Flexbox vs Grid：如何选择？

了解每种技术的优势和使用场景，为你的项目选择最合适的布局方案

使用 Flexbox 当...

  • 你需要一维布局（行或列）
  • 内容大小不确定，需要弹性调整
  • 需要对项目进行对齐、分布或排序
  • 构建导航栏、工具栏、卡片列表
  • 需要垂直或水平居中元素
  • 处理未知数量的项目

使用 Grid 当...

  • 你需要二维布局（行和列）
  • 需要精确控制项目的位置和大小
  • 构建复杂的整体页面布局
  • 创建响应式网格系统
  • 项目需要重叠或层叠
  • 需要创建不对称布局
重要提示

Flexbox和Grid不是互斥的，它们可以一起使用！ 实际上，最佳实践是结合使用两者：使用Grid进行整体页面布局，然后在Grid项目内部使用Flexbox进行内容排列。例如，用Grid创建页面区域（header, main, sidebar, footer），然后在导航栏（header内）使用Flexbox排列菜单项，在主内容区使用Flexbox排列卡片。

Flexbox示例：响应式导航栏

使用Flexbox创建自适应的导航栏，项目自动调整间距，在小屏幕上转换为汉堡菜单。

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 1rem 2rem;
  flex-wrap: wrap;
}

@media (max-width: 768px) {
  .navbar {
    flex-direction: column;
    align-items: flex-start;
  }
}

Grid示例：页面布局

使用Grid创建经典的页面布局，包含header、sidebar、main content和footer。

.container {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  gap: 20px;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
